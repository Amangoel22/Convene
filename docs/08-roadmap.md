# Convene

> One workspace to plan, coordinate, and execute events.

**Version:** 1.0
**Status:** Product Requirements Document (PRD)

---

# Overview

Convene is a modern Event Operations Platform designed to simplify the execution of physical events.

Unlike platforms such as Unstop, Devfolio, or Google Forms that primarily focus on registrations, Convene begins **after participant registrations are complete**.

Organizers import participant data into Convene, after which the platform becomes the single source of truth for managing both participants and the organizing team throughout the event lifecycle.

The goal is to eliminate the need for WhatsApp groups, Excel sheets, printed attendance registers, scattered Google Drive folders, and manual coordination.

---

# Problem Statement

Managing events today is fragmented.

A typical organizing team uses:

- WhatsApp for communication
- Excel for participant management
- Google Drive for documents
- Printed sheets for attendance
- Manual duty allocation
- Separate documents for inventory
- Verbal communication for live issues

As the event grows, this workflow becomes difficult to manage.

Important information gets buried, tasks become unclear, inventory is lost, and organizers lack a real-time view of operations.

Convene centralizes the entire operational workflow into one platform.

---

# Vision

Create an operating system for event execution.

Convene should become the workspace every organizer opens during an event.

Instead of asking:

- "Who has the HDMI cable?"
- "Has Team 42 arrived?"
- "Who is handling Registration?"
- "Where is the sponsor logo?"
- "What's happening next?"

The answer should already exist inside Convene.

# Product Philosophy

Convene is **not** another registration platform.

Convene is **not** another project management tool.

Convene is an operational workspace.

Every feature should answer one of these questions:

- What is happening right now?
- What needs attention?
- Who is responsible?
- What happens next?

# Design Principles

Convene should feel:

- Calm
- Premium
- Focused
- Modern
- Minimal

The interface should prioritize clarity over decoration.

No generic admin dashboards.

No unnecessary charts.

No oversized KPI cards.

No visual clutter.

The dashboard should function like a Mission Control panel rather than an analytics dashboard.
