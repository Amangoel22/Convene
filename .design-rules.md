# Convene Design Rules

- Never use charts unless necessary.
- Glass cards use 22px backdrop blur.
- Sidebar is always floating.
- Cards lift 3px on hover.
- Use Inter font.
- Maximum content width: 1600px.
- 8px spacing system only.
- No pure white backgrounds.
- Use monochrome Lucide icons.
- Tables always open details in a side drawer.
- Avoid full-page navigation when a drawer is sufficient.
